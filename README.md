## 📖 About

A web calculator built with **JavaScript** that looks good and
actually computes: includes a thoughtfully styled interface and the
core arithmetic logic in the `calculadora-indicadores` folder.

## ✨ Features

- Friendly, rounded UI
- Keyboard-friendly arithmetic logic
- Pure HTML/CSS/JS — no frameworks
